# GOD PEOPLE GATHERING

Church website — dark blue & yellow theme.

## Pages
- **Dashboard** (home) — daily affirmation, verse, gallery, quick links
- **Bible School** — reader, 4-week rotational study, endless rotational quiz
- **Newsletter** — covenant stories (Noah → Jesus) with images
- **Holy Spirit Baptism** — community & salvation by faith content
- **3 Days Prophetic Revivals** — Thu / Fri / Sat schedule + personal notes
- **Inspired By God** — one-time PDF upload/download
- Login / Sign Up

## Deploy (GitHub → Render Static Site)
1. Push this folder to GitHub
2. Render → New → Static Site → connect repo
3. Build: empty · Publish directory: `.`

No build step required. Pure static HTML/CSS/JS.
